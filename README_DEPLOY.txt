PROJECT TITAN PORTFOLIO V2 — NETLIFY DEPLOYMENT

Option A: Drag-and-drop replacement
1. Log in to Netlify.
2. Open your current site.
3. Go to Deploys.
4. Drag the entire Project_TITAN_Portfolio_V2 folder or its ZIP into the manual deploy area.
5. Wait for the deploy to publish.

Option B: Create a new site
1. Open Netlify Drop.
2. Drag Project_TITAN_Portfolio_V2.zip into the upload area.
3. Netlify will create a new live URL.

Important:
- index.html must stay at the root of the deployed folder.
- Do not upload only the assets folder.
- Test all four download buttons after deployment.
