Project TITAN is a self-directed biomedical engineering portfolio case study by **Michael Lozada-Longog**. It demonstrates a structured digital engineering workflow spanning product requirements, mechanical architecture, parametric CAD, static finite element analysis, engineering drawings, risk analysis, manufacturing planning, and prototype planning.

## Live site

**https://michaellozadalongog.github.io/project-titan-portfolio/**

## Engineering snapshot

| Item | Current baseline |
|---|---:|
| Documented components | 9 total: 7 custom + 2 commercial bearings |
| Shaft | Ø10 mm × 40 mm |
| Bearing center spacing | 31 mm |
| Plate and frame thickness | 6 mm |
| Simulated bearing loads | 2 × 2,000 N |
| Fusion-reported maximum stress | 54.947 MPa |
| Fusion-reported minimum safety factor | 2.377 |
| Fusion-reported maximum displacement | 0.102 mm |
| Controlled engineering documents | 10 |

> **Important:** The project is educational and has not been physically fabricated or experimentally validated. The material-property audit identified in the case study must be resolved before making a material-specific safety claim.

## GitHub Pages deployment

1. Place every file and folder in the **repository root**.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`.
5. Save and wait for the deployment to complete.

Do not upload the ZIP as the website. Extract it first, then upload the contents so `index.html` is visible at the repository root.

## Project boundary

Project TITAN is an educational portfolio project. It is not intended for clinical use, human testing, regulatory submission, or commercial deployment. Physical fabrication, dimensional inspection, fatigue testing, and experimental validation remain future work.
